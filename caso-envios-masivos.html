El problema

Una base de datos que
se pudre en silencio

El equipo de marketing usaba herramientas externas para enviar campañas. Pero nadie gestionaba lo que pasaba después del envío. Los rebotes se acumulaban silenciosamente sin que nadie limpiara la base.

Cada campaña llegaba a miles de correos muertos. La reputación del dominio se deterioraba. Los reportes de apertura eran inútiles porque incluían correos que ya no existían.

La BD vivía en una hoja de cálculo sin sistema que la depurara. Nadie sabía cuántos contactos eran realmente alcanzables. El costo mensual de la plataforma crecía junto con una lista cada vez más sucia.

  • Sin detección de rebotes — los correos muertos seguían en la BD indefinidamente
  • Reputación del dominio en riesgo — alta tasa de rebote penaliza la entregabilidad global
  • Métricas infladas — reportes incluían contactos inactivos o inexistentes
  • Costo creciente — plataformas cobran por volumen, incluyendo correos inválidos
  • Proceso manual — limpiar la BD requería revisión uno a uno o no se hacía
  • Sin historial de rebotes — no había forma de saber qué contacto falló ni cuándo
Arquitectura del sistema

Sheets como motor —
Gmail como canal nativo

El sistema corre completamente dentro del ecosistema Google. No hay servidor intermedio, no hay API de pago. Sheets lee la BD, Apps Script gestiona los envíos y el inbox captura los rebotes automáticamente.

📋
Fuente
Google Sheets
Base de datos de contactos. Nombre, correo, estado, historial de rebotes y fecha de último envío.
⚙️
Motor
Apps Script
Lee la BD, personaliza cada correo con {{NOMBRE}}, envía en lotes respetando límites de Gmail y registra el estado en tiempo real.
📧
Canal
Gmail nativo
Envío desde la cuenta corporativa. Sin API de terceros. Los correos llegan desde un dominio con reputación propia.
↩️
Captura
Inbox de rebotes
Gmail recibe automáticamente las notificaciones de fallo (MAILER-DAEMON). El sistema las lee y clasifica: hard bounce o soft bounce.
🧹
Limpieza
Actualización BD
Los contactos rebotados se marcan automáticamente en Sheets. Se excluyen de futuros envíos sin intervención manual.
Personalización

Cada correo se personaliza con el nombre del destinatario usando la variable {{NOMBRE}} en la plantilla HTML. El sistema lo reemplaza automáticamente en el asunto y en el cuerpo.

La plantilla se edita desde el propio panel de control. Sin acceso a código, sin despliegues — el equipo de marketing la actualiza directamente.

Motor de rebotes

La BD que se limpia
sola después de cada envío

El diferenciador real del sistema no es el envío — es la retroalimentación. Cada rebote que llega al inbox se convierte en datos que mantienen la base sana de forma automática.

01
Correo enviado
Gmail envía el correo personalizado. Si el destinatario no existe o el servidor rechaza la entrega, genera un mensaje de notificación automático.
Automático
02
Inbox captura el rebote
El MAILER-DAEMON llega al inbox del remitente. El sistema (vía Apps Script + label Rebotes_Seesoft) lo detecta, lo lee y extrae el correo fallido.
Automático
03
Clasificación del rebote
Se distingue entre hard bounce (dominio inexistente, usuario no encontrado) y soft bounce (buzón lleno, temporalmente inaccesible). Diferente tratamiento para cada uno.
Hard bounce Soft bounce
04
Actualización en Sheets
El correo rebotado se busca en la base de datos. Se actualiza su estado a "REBOTADO", se registra la fecha y el tipo de rebote. Queda excluido de siguientes campañas.
Automático
05
Panel de revisión
El botón "Revisar rebotados" en el panel muestra los correos procesados en la última sesión: cuántos se encontraron en BD, cuántos son nuevos, errores ignorados.
Manual / Revisión
06
BD siempre actualizada
Con cada campaña, la base mejora. Los rebotes acumulados se van depurando. La tasa de entregabilidad sube y la reputación del dominio se protege de forma continua.
Acumulativo
Label en Gmail

Los rebotes se acumulan automáticamente en la etiqueta Rebotes_Seesoft dentro de Gmail. El sistema escanea esa etiqueta en cada revisión y extrae los correos fallidos sin trabajo manual.
